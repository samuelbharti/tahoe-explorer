# How to cite

Please cite this repository when using it in publications or derivative projects.

Recommended citation (APA):

Bharti, S. (2026). *Tahoe Explorer: a Shiny app for exploring Tahoe-100M metadata* (version 0.1.1) [Software]. Zenodo. <https://doi.org/10.5281/zenodo.21926312>

BibTeX:

```bibtex
@software{tahoe_explorer_2026,
  author  = {Bharti, Samuel},
  title   = {Tahoe Explorer: a Shiny app for exploring Tahoe-100M metadata},
  version = {0.1.1},
  date    = {2026-08-14},
  doi     = {10.5281/zenodo.21926312},
  url     = {https://doi.org/10.5281/zenodo.21926312}
}
```

Notes:

- `10.5281/zenodo.21926312` is the concept DOI, and it always resolves to the
  latest version. To cite one specific version, use that version's DOI from the
  Zenodo record. The DOI of v0.1.0 is `10.5281/zenodo.21926313`.
- For automated citation support on GitHub, keep a `CITATION.cff` in the
  repository root.
- The datasets this app reads have their own citation requirements, which this
  citation does not replace. See "Data sources" in the README for Tahoe-100M,
  DepMap, and Cellosaurus.
